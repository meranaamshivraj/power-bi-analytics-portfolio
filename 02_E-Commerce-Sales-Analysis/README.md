# E-Commerce Sales Analysis | Power BI

## Project Overview
This project focuses on analyzing e-commerce sales transactions using Microsoft Power BI. The objective is to understand sales performance, customer purchasing behavior, product performance, and geographical sales distribution.

The project uses transaction-level retail data containing invoice details, product information, quantities, prices, customer IDs, and country information.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset Information
The dataset contains the following columns:

- InvoiceNo
- StockCode
- Description
- Quantity
- InvoiceDate
- UnitPrice
- CustomerID
- Country

## Project Objectives
- Analyze overall sales performance.
- Identify monthly and yearly sales trends.
- Find top-performing products.
- Analyze country-wise revenue.
- Understand customer purchasing behavior.
- Identify returning and new customers.
- Calculate important business KPIs.

## Data Cleaning & Preparation
- Handled missing values.
- Identified duplicate records.
- Checked cancelled transactions.
- Handled negative quantities and prices.
- Corrected data types.
- Created calculated columns for sales analysis.

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Orders
- Total Customers
- Total Products
- Average Order Value
- Total Quantity Sold
